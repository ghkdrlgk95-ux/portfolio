# 황기하 — SI 디지털 트윈 3D 포트폴리오

**공개 주소 : <https://ghkdrlgk95-ux.github.io/portfolio/>**

이 저장소는 GitHub Pages 로 서비스되는 포트폴리오 사이트입니다.
사이트는 손으로 고치지 않고, **전용 편집기에서 수정하면 자동으로 이 저장소에 올라갑니다.**

| 파일 | 역할 |
|---|---|
| `index.html` | 공개되는 사이트 — **자동 생성되므로 직접 수정하지 마세요** |
| `images/` | 사이트용 이미지 (편집기가 자동 추출·축소) |
| `videos/` | 영상 파일 (GitHub 제한: 파일당 100MB) |
| `editor.html` | 편집기 사본 (백업용) |
| `README.md` | 이 문서 |

편집기 본체(`HwangGiHa_Portfolio.html`, `편집기 실행.bat`, `_editor_server.py`)는
용량 때문에 저장소에 넣지 않고 로컬 폴더에 둡니다.


## 아래는 편집기 사용법입니다

## 1. 여는 방법

### ⚠️ `편집기 실행.bat` 을 더블클릭하세요

| 여는 방법 | 주소 | 저장 |
|---|---|---|
| **`편집기 실행.bat`** | `http://127.0.0.1:8765/…` | ✅ 저장 → 커밋 → 사이트 반영 |
| `HwangGiHa_Portfolio.html` 직접 | `file:///D:/…` | ❌ **안 됨** |

HTML 파일을 직접 열면 저장 버튼을 눌러도 이렇게만 뜹니다.

> `이 주소로는 파일에 못 씁니다 — '편집기 실행.bat'으로 여세요`

브라우저는 보안상 자기가 연 파일을 덮어쓸 수 없습니다.
그래서 `.bat` 이 작은 서버를 띄우고, **그 서버가 대신 파일에 쓰고 git 에 올립니다.**

실행하면 검은 창이 뜨고 브라우저가 자동으로 열립니다.
**편집하는 동안 검은 창은 켜둬야 합니다.** 닫으면 저장이 안 됩니다.

## 2. 전체 흐름

```
편집기 실행.bat  더블클릭
      ↓
브라우저에서 수정
      ↓
[저장] 클릭
      ├─ HwangGiHa_Portfolio.html      (편집용 원본)
      ├─ git 저장소의 index.html         (공개 사이트용)
      ├─ git 저장소의 images/            (이미지 자동 추출·축소)
      ├─ git commit                     (자동)
      └─ git push                       (자동)
      ↓
1~2분 뒤  https://ghkdrlgk95-ux.github.io/portfolio/  반영
```

저장 버튼을 누르면 상태가 순서대로 표시됩니다.

```
저장 중… 23.8MB
저장 + 커밋 완료, 올리는 중 (커밋 1개)
저장 + 사이트에 올림 (커밋 1개) - 1~2분 뒤 반영
```

마지막 줄까지 나오면 끝입니다. 따로 하실 일은 없습니다.

## 3. 편집 방법

### 글자

아무 글자나 **클릭하면 바로 수정**됩니다. 제목, 설명, 지표 값, 메타바 항목명까지 전부요.

### 이미지 칸

| 동작 | 방법 |
|---|---|
| 이미지 넣기 / 바꾸기 | 칸을 **클릭** → 파일 선택 |
| 위치 옮기기 | 이미지를 **끌기** |
| 확대 / 축소 | 이미지 위에서 **마우스 휠** |
| 가로만 조절 | **오른쪽 모서리** 끌기 (↔) |
| 세로만 조절 | **아래쪽 모서리** 끌기 (↕) |
| 가로·세로 같이 | **우하단 꼭짓점** 끌기 (⤡) |
| 원래 크기로 | 아무 모서리나 **더블클릭** |
| 잠그기 | 🔓 클릭 → 🔒 |
| 삭제 | × 클릭 |

**🔒 잠그면** 이동·확대·크기조절·삭제·교체가 전부 막힙니다.
위치를 잡아둔 이미지가 실수로 틀어지는 걸 막으려면 잠가두세요.

### 동영상 칸

- **재생**은 편집 중에도 됩니다. 그냥 누르면 재생됩니다.
- **링크 바꾸기**는 우상단 **🔗** 버튼으로 합니다.
- 넣을 수 있는 주소
  - `videos/파일이름.mp4` — 저장소에 있는 영상 (권장)
  - YouTube · Vimeo 주소
  - 구글 드라이브 **파일** 공유 링크 (폴더 링크는 안 됨)

### 항목 추가

각 섹션 맨 아래에 버튼이 있습니다.

- `+ 글 상자 추가`
- `+ 큰 이미지 추가` — 가로 전체를 쓰는 이미지 칸
- `+ 동영상 추가`
- `+ 이미지 추가` — 이미지 묶음 안에 한 칸 더
- `+ 지표 추가` — 숫자 카드 한 장 더

새 항목은 **버튼 앞에** 들어가고, 버튼은 항상 맨 뒤에 남습니다.

### 섹션 순서 바꾸기

섹션 맨 위 손잡이를 씁니다.

```
⠿⠿ 섹션 이동 5 / 10   ▲ ▼
```

- **▲** 한 칸 위로 / **▼** 한 칸 아래로
- 지금 몇 번째인지 항상 숫자로 표시됩니다
- 옮기면 `섹션 이동됨 · 5번째 → 4번째` 로 알려줍니다
- 맨 위·맨 아래에서는 해당 버튼이 흐리게 비활성됩니다

가까운 거리는 손잡이를 잡고 끌어도 됩니다. 다만 섹션이 길어서 **버튼이 확실합니다.**

## 4. 문제가 생겼을 때

### 저장이 안 됩니다

**검은 창이 닫혔는지 확인하세요.** 닫혔으면 `편집기 실행.bat` 을 다시 실행하고 브라우저에서 **F5**.

### `이 탭은 오래된 내용입니다 (탭 N / 파일 M)`

탭을 오래 열어둔 사이 파일이 바뀌었다는 뜻입니다. **당황하지 않으셔도 됩니다.**

- 파일은 덮어쓰이지 **않았습니다**
- 그 탭의 수정 내용은 `_backup` 폴더에 `충돌본_날짜_탭N_파일M.html` 로 **자동 보관**됩니다
- **F5** 로 새로고침한 뒤 이어서 작업하시면 됩니다

### `GitHub 로그인이 저장돼 있지 않습니다`

터미널에서 한 번만 실행해 로그인해 두세요. 이후로는 자동입니다.

```
git -C "D:/YMX_gh 개인/GH자료/git/portfolio" push origin main
```

로그인이 안 돼 있어도 **저장과 커밋은 정상 동작**하니 작업물은 안전합니다.
나중에 위 명령 한 번이면 밀린 게 전부 올라갑니다.

### 사이트에 바로 안 보입니다

- GitHub Pages 재빌드에 **1~2분** 걸립니다
- 브라우저 캐시가 **최대 10분** 남습니다

바로 확인하려면 **시크릿 창**으로 열거나 **Ctrl + F5**.

## 6. 알아두면 좋은 것

### 영상 넣기

영상은 HTML 에 넣을 수 없어서 **파일로 저장소에 둡니다.**

- 위치 : `GH자료\git\portfolio\videos\`
- **GitHub 제한 : 파일당 100MB** — 넘으면 안 올라갑니다
- 원본이 크면 압축이 필요합니다 (지금 있는 것들은 3.7GB → 255MB 로 줄여 넣은 것)
- 편집기에는 `videos/파일이름.mp4` 로 넣으면 됩니다
- 같은 이름의 `.jpg` 를 옆에 두면 재생 전 첫 화면으로 쓰입니다

### 폰 대응

폰에서는 자동으로 다르게 보입니다. **따로 하실 건 없습니다.**

- 칸들이 화면 폭에 맞춰 줄어들고 세로로 하나씩 쌓임
- 이미지는 가로세로 비율이 유지됨
- 글자가 길면 칸이 늘어남 (잘리지 않음)

PC 에서 잡아둔 이미지 확대·위치는 폰에서 약간 달라집니다. 좁은 화면에 그대로 쓸 수 없어서, 폰에서는 이미지가 칸을 채우도록 처리됩니다.

### 백업

- 저장할 때마다 직전 파일이 `_backup` 에 남습니다 (최근 5개)
- 편집본이 개당 25MB 라 폴더가 100MB 를 넘길 수 있습니다
- **지워도 됩니다.** 편집·저장에 영향 없고 다음 저장 때 새로 만들어집니다

### 링크 공유

주소를 걸어둔 곳은 저장만 하면 **전부 자동으로 최신**이 됩니다.

| 어떻게 공유했나 | 자동 갱신 |
|---|---|
| 주소를 적어둠 (이력서, 채용사이트 링크란, 메일 서명) | ✅ |
| HTML 파일을 첨부해서 보냄 | ❌ |
| PDF 로 내보내 올림 | ❌ |
| 채용사이트에 파일 업로드 | ❌ |

**파일이 아니라 주소로 공유**해 두시는 게 앞으로 편합니다.
